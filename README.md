# ktk-schedule

Telegram бот для просмотра расписания КТК.

## Возможности

- Авторизация через workspace
- Просмотр расписания по дням
- Утренние уведомления

## ⚠️ Disclaimer

Проект использует публичный API стороннего сервиса.
Автор не связан с КТК и не несёт ответственности за изменения API.
